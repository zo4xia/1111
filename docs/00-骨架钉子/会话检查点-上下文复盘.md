## 7. 不可违背铁律（改代码前默念）
- 漏斗：org_id 隔离一切，登录三要素，绝不串村；SQL 必带 org_id。
- 提案 approve 是唯一数据源头：Dday/岗位/日程/公告一次锁定，下游只读+微调，禁止重复造。
- 公告唯一挂日程阶段；未到时间参选人端隐藏。
- 角色权限：超管建角色管子管理；子管理本归属地增删人员+审批；经办编辑可编辑不可审批；审核员可审批不可编辑；参选人只有提交/下载/看公示，前端隐藏一切按钮。
- 无「选民」业务；村 vs 社区仅选举方式(村=全民直选；社区=全民直选/户代表/居民代表)与岗位细节差异。
- 能复用不手搓、TDesign 一套 UI；脱稿注释（数据接入点写清接口路径）。

## 8. 踩过的坑（别再踩）
- TDesign React Table cell 签名是 `({row})`，写 `(h,{row})` 会从 undefined 解构直接白屏。
- Steps 的 StepItem description 在本版本不渲染，审核明细要自己在下方列。
- Descriptions 用 items 属性是对的；Page 组件只吃 breadcrumbs/isFullPage，不吃 title/desc。
- PowerShell 内联 python 遇引号/< 必炸，复杂改写独立 .py 文件再执行。
- g5/g6 他人代码有别平台硬编码和错误「选民」模型，Router basename=/app 与 /client 不匹配会空白，只可抄 UI。
- 飞书方案已废弃，不要再接。
